Uso rápido

  • Pulsa Ctrl+K (⌘K en Mac) o «Buscar» en la cinta para encontrar cualquier raza, clase, dote, conjuro, monstruo o personaje y abrir su detalle.
  • Usa la cinta superior para abrir Archivo, Manuales, Opciones y Ayuda.
  • Las pestañas se abren una sola vez; si ya existen, la web te lleva a ellas.
  • Pulsa Esc para cerrar la pestaña activa cuando sea cerrable.
  • La navegación intenta devolverte a la pestaña desde la que abriste el contenido actual.
  • Tu perfil y la ayuda no se abren por defecto.

Acerca del proyecto

Fichas 3.5 es una aplicación web orientada a consulta, creación y gestión de fichas y catálogos de D&D 3.5.

El proyecto sigue en evolución y combina catálogo, navegación por pestañas, perfil de usuario y herramientas de administración para mantener los datos sincronizados.
